**Goal:** `-o cyclonedx` on `scan`, `scan-batch` and `scan-org` writes a CycloneDX 1.6 JSON BOM of the repository's AI inventory (framework, models, agents with instances, tools, MCP servers, LLM endpoints) and its OSV vulnerabilities.

## Background for the implementer

- `ScanReport` (`src/quin_scanner/models.py`) fields used here: `repo_path` (absolute local path, or `owner/repo` for GitHub targets), `scan_timestamp` (ISO 8601 with offset), `framework` (e.g. `"CrewAI 0.80.0"`), `agents: list[AgentProfile]`, `tool_usages: list[ToolUsage]`, `model_usages: list[ModelUsage]`, `mcp_servers: list[MCPServer]`, `llm_endpoints: list[EndpointUsage]`, `vulnerabilities: list[Vulnerability]`.
- `AgentProfile`: `id` (`agent:<name>` etc.), `name`, `identity` (`strong`/`weak`), `scope` (`production`/`test`/`example`), `instances: list[AgentInstance]`. Fields `goal`, `agent_type`, `capabilities`, `risk_signals`, `flags`, `provenance` are **not** exported.
- `AgentInstance`: `id`, `file`, `line`, `scope`, `multiplicity` (`one`/`many`), `model` (literal like `gpt-4o`, or reference `env:X`, `var:x.y`, or a call text containing `(`), `tools: list[InstanceTool]` (`name`, `tool_id`, `resolved`), `tools_known`.
- `ToolUsage`: `tool_name`, `tool_type`, `service_category` (**not exported**: the LLM can fill it), `source_file`, `line_number`, `id`, `scope`.
- `ModelUsage`: `provider`, `model_name`, `file_path`, `line_number`. `MCPServer`: `name`, `transport`, `source_file`. `EndpointUsage`: `url` (redacted), `host`, `kind` (`unresolved` means no address was found).
- `Vulnerability`: `cve_id`, `severity`, `cvss_score`, `published`, `summary`, `source` (`osv` or `web:<provider>`), `source_url`.
- `parse_framework_ref(report.framework)` in `vuln_checker.py` returns a `FrameworkRef(name, version, ecosystem, package)` or `None`. Ecosystems in the lookup table are `PyPI` and `npm` (e.g. package `@mastra/core`).
- The CLI contract: `tests/cli_snapshot.json` must be regenerated when options change; `tests/cli_baseline_1.0.json` is frozen and must not be edited; `docs/cli.md` is generated by `scripts/gen_cli_reference.py`.

```python
"""Validates CycloneDX 1.6 BOMs against the vendored official schema, offline."""
from __future__ import annotations

import json
from functools import lru_cache
from pathlib import Path

from jsonschema import Draft7Validator, FormatChecker
from referencing import Registry, Resource
from referencing.jsonschema import DRAFT7

SCHEMA_DIR = Path(__file__).resolve().parent / "cyclonedx_schema"
_FILES = ("bom-1.6.schema.json", "spdx.schema.json", "jsf-0.82.schema.json")


@lru_cache(maxsize=1)
def _validator() -> Draft7Validator:
    schemas = {name: json.loads((SCHEMA_DIR / name).read_text(encoding="utf-8")) for name in _FILES}
    # bom-1.6 refers to the other two by relative URI; register them under their $id so nothing is fetched.
    registry = Registry().with_resources(
        (schema["$id"], Resource.from_contents(schema, default_specification=DRAFT7)) for schema in schemas.values()
    )
    return Draft7Validator(schemas["bom-1.6.schema.json"], registry=registry, format_checker=FormatChecker())


def bom_errors(bom: dict) -> list[str]:
    """Schema errors as "path: message" strings; empty when the BOM is valid."""
    return sorted(f"{'/'.join(map(str, e.absolute_path))}: {e.message}" for e in _validator().iter_errors(bom))
```

```python
"""Serializes a ScanReport's AI inventory to a CycloneDX 1.6 BOM (AI components only).

Only static inventory is exported: nothing the LLM can write, so the same commit gives the same BOM
apart from serialNumber and metadata.timestamp. Spec: docs/superpowers/specs/2026-11-02-cyclonedx-ai-bom-design.md
"""
from __future__ import annotations

import json
import re
import uuid
from datetime import datetime, timezone
from typing import Any

from quin_scanner.models import ScanReport

SPEC_VERSION = "1.6"
ROOT_REF = "repo"


class _Refs:
    """Hands out bom-refs, unique across the BOM: a value already taken gets #2, #3, ..."""

    def __init__(self) -> None:
        self._taken: set[str] = {ROOT_REF}

    def take(self, ref: str) -> str:
        candidate, n = ref, 1
        while candidate in self._taken:
            n += 1
            candidate = f"{ref}#{n}"
        self._taken.add(candidate)
        return candidate


def _repo_name(repo_path: str) -> str:
    """owner/repo for GitHub targets, the directory name for local paths."""
    clean = re.sub(r"[\\/]+$", "", repo_path).removesuffix(".git")
    if re.fullmatch(r"[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+", clean):
        return clean
    return re.split(r"[\\/]", clean)[-1] or "repository"


def _iso_utc(value: str | None) -> str | None:
    """An ISO 8601 date or date-time as a UTC date-time (YYYY-MM-DDTHH:MM:SSZ), or None when unparsable."""
    if not value:
        return None
    text = value.strip()
    if re.fullmatch(r"\d{4}-\d{2}-\d{2}", text):
        text += "T00:00:00"
    try:
        parsed = datetime.fromisoformat(text.replace("Z", "+00:00"))
    except ValueError:
        return None
    if parsed.tzinfo is None:
        parsed = parsed.replace(tzinfo=timezone.utc)
    return parsed.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")


def _metadata(report: ScanReport) -> dict[str, Any]:
    from quin_scanner import __version__

    timestamp = _iso_utc(report.scan_timestamp) or datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    return {
        "timestamp": timestamp,
        "tools": {"components": [{"type": "application", "name": "quin-scanner", "version": __version__}]},
        "component": {"type": "application", "bom-ref": ROOT_REF, "name": _repo_name(report.repo_path)},
    }


def _dependencies(graph: dict[str, set[str]]) -> list[dict[str, Any]]:
    out = []
    for ref in sorted(graph):
        entry: dict[str, Any] = {"ref": ref}
        if graph[ref]:
            entry["dependsOn"] = sorted(graph[ref])
        out.append(entry)
    return out


def build_bom(report: ScanReport) -> dict[str, Any]:
    """The CycloneDX 1.6 BOM for *report* as a plain dict."""
    graph: dict[str, set[str]] = {ROOT_REF: set()}
    bom: dict[str, Any] = {
        "bomFormat": "CycloneDX",
        "specVersion": SPEC_VERSION,
        "serialNumber": f"urn:uuid:{uuid.uuid4()}",
        "version": 1,
        "metadata": _metadata(report),
    }
    bom["dependencies"] = _dependencies(graph)
    return bom


def to_cyclonedx(report: ScanReport) -> str:
    return json.dumps(build_bom(report), indent=2, ensure_ascii=False)
```

```python
def _purl(ref: FrameworkRef) -> str | None:
    """Package URL of the framework package, or None for an ecosystem without a mapping."""
    version = quote(ref.version, safe="")
    ecosystem = ref.ecosystem.lower()
    if ecosystem == "pypi":
        return f"pkg:pypi/{re.sub(r'[-_.]+', '-', ref.package).lower()}@{version}"
    if ecosystem == "npm":
        namespace, _, name = ref.package.rpartition("/")
        path = f"{quote(namespace, safe='')}/{quote(name, safe='')}" if namespace else quote(name, safe="")
        return f"pkg:npm/{path}@{version}"
    return None


def _framework(report: ScanReport) -> dict[str, Any] | None:
    ref = parse_framework_ref(report.framework)
    purl = _purl(ref) if ref else None
    if ref is None or purl is None:
        return None

    severity = v.severity if v.severity in _SEVERITY_ORDER else "unknown"
    rating: dict[str, Any] = {}
    if v.cvss_score is not None:
        rating["score"] = v.cvss_score
    rating["severity"] = severity
    source: dict[str, Any] = {"name": "OSV"}
    if v.source_url:
        source["url"] = v.source_url
    out: dict[str, Any] = {"bom-ref": f"vuln:{v.cve_id}", "id": v.cve_id, "source": source, "ratings": [rating]}
    if v.summary:
        out["description"] = v.summary
    published = _iso_utc(v.published)
    if published:
        out["published"] = published
    out["affects"] = [{"ref": framework_ref}]
    return out


def _vulnerabilities(report: ScanReport, framework_ref: str | None) -> list[dict[str, Any]]:
    """OSV entries with an ID only: web-search results can differ between runs (spec D2)."""
    if framework_ref is None:
        return []
    picked: dict[str, Vulnerability] = {}

        if v.source == "osv" and v.cve_id and v.cve_id not in picked:
            picked[v.cve_id] = v
    ordered = sorted(picked.values(), key=lambda v: (_SEVERITY_ORDER.get(v.severity, 6), v.cve_id))
    return [_vulnerability(v, framework_ref) for v in ordered]

    return sum(1 for v in report.vulnerabilities if v.source != "osv")
```

```markdown
# AI-BOM (CycloneDX)

`-o cyclonedx` writes the AI parts of a repository as a [CycloneDX 1.6](https://cyclonedx.org/docs/1.6/json/) JSON BOM:

    quin-scanner scan ./my-agent-app -o cyclonedx -f ai-bom.cdx.json

It works on `scan`, `scan-batch` and `scan-org` (one BOM per repository, named `<repo>_<timestamp>.cdx.json`).

The BOM holds AI components only. For packages, generate an SBOM with [syft](https://github.com/anchore/syft) or
[cdxgen](https://github.com/CycloneDX/cdxgen) and combine the two with the
[CycloneDX CLI](https://github.com/CycloneDX/cyclonedx-cli):

    syft dir:./my-agent-app -o cyclonedx-json=sbom.cdx.json
    cyclonedx merge --input-files sbom.cdx.json ai-bom.cdx.json --output-file full.cdx.json

Both files can also be uploaded to the same project in Dependency-Track.

## What is in it

| Quin item | CycloneDX | `bom-ref` |
|---|---|---|
| Repository | `metadata.component` (`application`) | `repo` |
| Detected framework and version | component, `type: framework`, with `purl` | the purl, e.g. `pkg:pypi/crewai@0.80.0` |
| Model with a literal name | component, `type: machine-learning-model`, `publisher` = provider; each use is an occurrence | `model:<provider>/<name>` |
| Agent | component, `type: application`, property `quin:kind=agent`; each instance is an occurrence | the agent ID, e.g. `agent:researcher` |
| Tool | component, `type: application`, property `quin:kind=tool`; its definition is an occurrence | the tool ID, e.g. `tool:search` |
| MCP server | service | `service:mcp:<name>` |
| LLM endpoint (resolved address) | service, `endpoints` = redacted URLs, one per host | `service:endpoint:<host>` |
| OSV vulnerability in the framework | vulnerability, `affects` = the framework | `vuln:<id>` |

Agents whose instances are all in test or example code have `scope: excluded`; production agents have `scope: required`.

Each agent instance is an `evidence.occurrences` entry with the file, the line, the instance ID as `bom-ref`, and an
`additionalContext` string such as `scope=test; model=gpt-4o; tools=search,scrape`. `tools=unknown` means the tools
could not be read from the code (e.g. `tools=get_tools()`); `multiplicity=many` means the agent is created in a loop.

The `dependencies` graph links the repository to the framework, every agent and every service, and each agent to the
tools and models it is given.

### `quin:` properties

| Property | On | Values |
|---|---|---|
| `quin:kind` | agents, tools | `agent`, `tool` |
| `quin:identity` | agents | `strong` (literal name in code), `weak` (no literal name) |
| `quin:tool-type` | tools | `tool_definition`, `external_service`, `skill`, `mcp_tool` |
| `quin:transport` | MCP servers | `stdio`, `http`, `sse`, `unknown` |
| `quin:source-file` | MCP servers | file the server is configured in |
| `quin:endpoint-kind` | endpoints | `hosted_provider`, `local`, `private`, `remote`, `unknown` |

## What is left out, and why

- **Anything the LLM writes**: agent goals, types and capabilities, tool service categories, and the unverified
  `llm_inferred_agents` / `llm_inferred_tools`. The BOM is built from static evidence only, so the same commit gives the
  same BOM with or without an LLM key. Only `serialNumber` (new for every BOM, as the CycloneDX spec requires) and
  `metadata.timestamp` change between runs.
- **Web-search vulnerabilities**: results from `--vuln-search-provider` can differ between runs and sometimes have no
  advisory ID. The BOM carries OSV results only; Quin prints how many web-search results it left out. They remain in
  the JSON and HTML reports.
- **Risk signals and inventory flags** such as tool divergence: the BOM is an inventory. Use the JSON report or SARIF
  for risks.
- **Package dependencies**: use syft or cdxgen (above).
```
